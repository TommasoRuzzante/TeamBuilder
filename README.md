Progetto grezzo realizzato 4fun per un'applicazione che consenta la creazione di squadre equilibrate ai calcetti tra amici.
Le valutazioni dei giocatori sono date dall'utente, il quale deve essere più oggettivo possibile (l'applicazione non può togliere soggettività alla valutazione).
L'algoritmo che suddivide in due le squadre è un algoritmo di Programmazione Dinamica realizzato con l'IA. Dopo vari test con altri algoritmi è stato certificato
essere l'algoritmo migliore.
